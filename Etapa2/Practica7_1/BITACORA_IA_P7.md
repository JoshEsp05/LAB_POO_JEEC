# BITACORA IA – Práctica #7

## Prompts utilizados
- Cómo usar clases abstractas en Java  
- Ejemplo de herencia y polimorfismo  
- Uso de interfaces en Java  

## Qué respondió la IA
Me explicó cómo funcionan las clases abstractas, las interfaces y el polimorfismo. También me mostró ejemplos de cómo estructurar una clase padre y una clase hija, y cómo sobrescribir métodos.

## Qué hice con eso
Usé la idea general para crear mi clase Transporte como abstracta y la clase Automovil como hija. Implementé interfaces para los métodos de avanzar y frenar, y adapté el código para que coincidiera con lo que pedía la práctica.

## Qué cambié o no usé
No usé exactamente los ejemplos que me dio, ya que ajusté nombres de métodos, atributos y la salida. También corregí errores de sintaxis y detalles de implementación.

## Qué aprendí
Aprendí cómo usar herencia, clases abstractas e interfaces en conjunto, y cómo aplicar polimorfismo en Java.
