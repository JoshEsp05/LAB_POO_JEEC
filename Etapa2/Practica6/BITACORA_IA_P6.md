# BITACORA IA – Práctica #6

## Prompts utilizados
- Cómo crear clases en Java (POO)
- Uso de arreglos de objetos
- Ejemplo de Teléfono y Contacto
- Error con nombres de clases en Java

## Qué respondió la IA
Explicó cómo usar clases, encapsulamiento y arreglos de objetos. También ayudó a detectar errores en el uso de nombres de clases.

## Qué hice con eso
Creé las clases ClaseTelefono y ClaseContacto, y un arreglo de 5 objetos de cada uno en el main para simular funciones de teléfono.

## Qué cambié o no usé
Corregí los nombres de las clases en el main y ajusté algunos mensajes de salida.

## Qué aprendí
Aprendí a usar clases, objetos y arreglos en Java, y la importancia de nombrar correctamente las clases.
