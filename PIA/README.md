# GymPOS

GymPOS es un sistema de gestión para gimnasios desarrollado en Java y JavaFX utilizando arquitectura MVC.

El sistema permite administrar clientes, membresías, inventario de equipos, acceso al gimnasio, calendario de clases grupales y generación de reportes.

---

# Tecnologías utilizadas

- Java
- JavaFX
- FXML
- Arquitectura MVC
- Serialización de archivos (.dat)
- Visual Studio Code

---

# Funcionalidades principales

- Gestión de clientes (CRUD)
- Sistema de membresías
- Validación de acceso al gimnasio
- Control de inventario
- Calendario de clases grupales
- Sistema de puntos y recompensas
- Generación de reportes
- Persistencia de datos

# Como ejecutar el Proyecto 

1. **Clonar el repositorio**
   git clone https://github.com/JoshEsp05/LAB_POO_JEEC.git

2. **Abrir la carpeta del proyecto**
   Abrir la carpeta: `GymPOS`

3. **Entrar a la carpeta dist**
   Ruta: `GymPOS/dist/`

4. **Ejecutar el sistema**
   Hacer doble click en el archivo: `Abrir_GymPOS.bat`

---

# Requisitos

- **Java JDK 21** o superior.
- **Windows** (requerido para ejecutar el archivo .bat).
- **Git** (opcional para clonar el repositorio).

---

# Persistencia de datos

El sistema guarda automáticamente la información en archivos `.dat` dentro de la carpeta:
