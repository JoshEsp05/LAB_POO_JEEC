# BITACORA IA – Práctica #13

## Prompts utilizados
- Qué es debug en programación
- Ejemplos de manejo de errores

## Qué respondió la IA
Me sugirió agregar mensajes de control en el programa y validar los datos de entrada para detectar errores más fácilmente.

## Qué hice con eso
Agregué mensajes tipo [DEBUG] en partes importantes del código para ver qué estaba pasando durante la ejecución. También validé que el usuario no ingresara datos incorrectos y manejé errores en la entrada.

## Qué cambié o no usé
No usé herramientas de debug avanzadas, solo trabajé con la consola. También traté de no poner demasiados mensajes para que el programa no se viera saturado.

## Qué aprendí
Aprendí que el debug es muy importante para encontrar errores y mejorar el programa. También entendí mejor cómo validar datos y manejar errores.
