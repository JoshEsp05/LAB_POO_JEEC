# BITACORA IA – Práctica #11

## Prompts utilizados
- Cómo guardar datos en un archivo en Java
- Cómo usar try catch finally en Java
- Ejemplo de lectura y escritura de archivos

## Qué respondió la IA
Me mostró ejemplos de cómo usar BufferedReader y BufferedWriter para guardar información en archivos de texto, y cómo usar try-catch para evitar errores al leer o escribir.

## Qué hice con eso
Tomé la idea general pero adapté el código a lo que ya tenía de mi práctica. Cambié el arreglo por un ArrayList para poder manejar más contactos y usé un formato sencillo para guardarlos (nombre y número separados por coma).

## Qué cambié o no usé
Algunos ejemplos usaban rutas completas del sistema, pero decidí usar un archivo simple dentro del proyecto para evitar problemas. También simplifiqué partes del código que estaban más complejas de lo necesario.

## Qué aprendí
Aprendí a guardar y leer datos desde un archivo en Java, y entendí mejor cómo funcionan las excepciones y por qué es importante usarlas.
