# BITACORA IA – Práctica #10

## Prompts utilizados
- Cómo leer y escribir archivos  
- Ejemplo de FileWriter  
- Cómo usar Scanner para leer archivos  

## Qué respondió la IA
Me explicó cómo trabajar con archivos usando FileWriter, File y Scanner, además del uso de try-catch para manejar errores.

## Qué hice con eso
Implementé programas para escribir en un archivo, leer su contenido y un programa combinado que realiza ambas funciones.

## Qué cambié o no usé
Modifiqué rutas de archivos y simplifiqué el manejo de entrada. También ajusté los mensajes para que fueran más claros.

## Qué aprendí
Aprendí a manejar archivos en Java, tanto para lectura como escritura, y a usar excepciones para evitar errores.
