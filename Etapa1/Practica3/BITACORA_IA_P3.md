# BITACORA IA – Práctica #3

## Prompts utilizados
- Cómo crear métodos en Java
- Ejemplo de clase Calculadora

## Qué respondió la IA
Explicó cómo realizar operaciones aritméticas en Java, usar Scanner para leer datos y cómo separar el código en una clase con métodos.

## Qué hice con eso
Primero hice un programa con operaciones básicas dentro del main. Después creé una clase Calculadora con métodos para suma y resta, y la utilicé desde el main.

## Qué cambié o no usé
Ajusté los nombres de variables y la forma de imprimir resultados. También simplifiqué algunas funciones.

## Qué aprendí
Aprendí a usar Scanner, realizar operaciones básicas y organizar el código usando clases y métodos.
