# BITACORA IA – Práctica #2

## Prompts utilizados
- Tipos de datos primitivos en Java
- Uso de Scanner para entrada de datos
- Cómo imprimir datos en consola

## Qué respondió la IA
Explicó cómo crear un programa básico en Java, el uso de System.out.println y cómo utilizar Scanner para leer datos como nombre, edad y teléfono.

## Qué hice con eso
Realicé programas para imprimir "Hola Mundo", mostrar tipos de datos primitivos y pedir datos al usuario para después imprimirlos en consola.

## Qué cambié o no usé
Ajusté los mensajes de salida y el formato de impresión. También adapté el uso de Scanner para que fuera más claro.

## Qué aprendí
Aprendí lo básico de Java, entrada y salida de datos, y cómo usar Scanner para interactuar con el usuario.
